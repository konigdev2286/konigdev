## 🛠 Stack Technique
- **Framework** : [Next.js 14](https://nextjs.org/) (App Router, React 18, TypeScript)
- **Styling** : Tailwind CSS, CSS Animations fluides
- **Typographie** : Plus Jakarta Sans, Playfair Display, JetBrains Mono
- **Design System** : Épuré, fond clair, vert néon `#39FF14` & noir profond `#0D0D11`
- **Icônes** : Simple Icons & Lucide

## ✨ Fonctionnalités Clés
- **Curseur interactif dynamique** : Rond avec logo KoniG.dev et inversion chromatique `mix-blend-mode: difference` au survol de chaque couleur.
- **Marquee infini** : Défilement fluide de gauche à droite des technologies maîtrisées.
- **Section Méthode Orbitale** : Cycle rotatif à 360° des 4 étapes de travail avec contre-rotation lisible, hub interactif et contrôle Play/Pause.
- **Section Services en Livre 3D** : Tournage interactif de pages pour découvrir les expertises.
- **Section À propos Cinématique** : Bloc sombre respirant qui s'agrandit et rétrécit dynamiquement au scroll.

## 🚀 Démarrage Local

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Compiler pour la production
npm run build
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.
